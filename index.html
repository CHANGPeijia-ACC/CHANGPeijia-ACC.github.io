Voucher Data Analysis Toolkit凭证数据分析工具

github.com/CHANGPeijia-ACC/voucher-analysis

A Python toolkit that validates, summarises and reconciles accounting voucher data.

用 Python 完成凭证数据的校验、汇总与对账。

Problem
Voucher review in practice means scrolling spreadsheets by hand — checking that every entry balances, that nothing is missing, and that the totals agree with the ledger. It is slow and it is exactly the kind of work that hides errors.
实务中复核凭证靠人工翻表格 —— 逐条检查借贷是否平、有没有缺项、合计与账簿是否一致。既慢，又恰好是最容易藏错的环节。
Approach
Written in Python using only the standard library (csv), so it runs on a client machine with nothing to install. Covers validation (voucher-number format, missing or non-numeric amounts, negative amounts flagged for review), monthly aggregation, a month × account cross-tab, per-account outlier detection against each account’s own mean, and two-way reconciliation against a bank statement that matches on voucher number rather than row order. Logic is packaged into reusable functions rather than one long script.
仅用 Python 标准库（csv）编写，在客户现场的电脑上无需安装任何依赖即可运行。涵盖数据校验（凭证号格式、金额缺失或非数字、负数金额提示人工确认）、月度汇总、月份 × 科目交叉汇总、以各科目自身均值为基准的分组异常检测，以及与银行流水之间按凭证号（而非行序）配对的双向对账。逻辑封装为可复用函数，而非一次性长脚本。
Result
Takes a voucher file and a bank statement and writes four CSVs — monthly summary, month × account cross-tab, flagged outliers, and a difference list separating book-only, bank-only and amount-mismatch items — replacing the manual spreadsheet pass.
输入一份凭证文件与一份银行流水，输出四个 CSV —— 月度汇总、月份 × 科目交叉表、异常清单，以及区分「只在账簿有 / 只在银行有 / 金额不一致」的差异表，替代原本的手工表格作业。

Singapore Government Procurement — Audit Analysis新加坡政府采购审计分析

github.com/CHANGPeijia-ACC/sg-procurement-analysis

A pandas analysis of 18,464 public contract awards, screening for supplier concentration, threshold clustering and leading-digit anomalies.

用 pandas 分析 18,464 条政府中标记录，筛查供应商集中度、金额阈值聚集与首位数字异常。

Problem
Singapore publishes every government contract award through GeBIZ, but the file is a flat list of 18,464 rows. It records what was bought; it does not show which agencies depend on a single supplier, or whether contracts are being kept just under the value that would trigger an open tender. Answering those questions means rebuilding the data first.
新加坡通过 GeBIZ 公开每一笔政府采购中标记录，但拿到手的是一张 18,464 行的平表。它记录了买了什么，却看不出哪些机构依赖单一供应商，也看不出合同金额是否被压在公开招标门槛之下。要回答这些问题，得先把数据重建一遍。
Approach
Python with pandas. Supplier names were normalised conservatively — case, punctuation and legal-suffix spelling only — after spot checks showed that keyword matching would merge separately registered companies and overstate concentration. Concentration is measured as HHI and CR4 per agency; threshold clustering is tested with progressively narrower windows around Singapore’s published S$6,000 and S$90,000 procurement limits; leading digits are tested against Benford’s Law with a scipy chi-square test.
Python 与 pandas。供应商名称的标准化刻意保守 —— 只处理大小写、标点与法定后缀写法；因为抽查发现，按关键词合并会把不同的注册公司并成一家，从而虚高集中度。集中度按机构计算 HHI 与 CR4；阈值聚集用逐步收窄的窗口，检验新加坡公布的 6,000 与 90,000 新元采购门槛；首位数字用 scipy 卡方检验与 Benford 定律对比。
Result
One agency with 64 suppliers on record still reaches an HHI of 8,314 — its spend is dominated by a single contract. Award counts spike in the S$88,000–89,000 band just below the S$90,000 open-tender threshold, and the below-to-above ratio sharpens from 1.25× to 1.61× as the window narrows, which is the signature of clustering rather than noise. Leading digits fit Benford’s Law once amounts under S$1,000 are excluded (p = 0.12). Each finding is published with its limitations: these are screening signals, not proof.
某机构名下有 64 家供应商，HHI 仍达 8,314 —— 金额被单一合同占据。中标金额在 88,000–89,000 新元区间出现尖峰，正好卡在 90,000 新元公开招标门槛之下；窗口越收窄，下方与上方的比值从 1.25 倍升到 1.61 倍，这是聚集而非噪声的特征。剔除 1,000 新元以下的小额后，首位数字与 Benford 定律吻合（p = 0.12）。每条结论都附上了局限：这些是筛查信号，不是证据。
